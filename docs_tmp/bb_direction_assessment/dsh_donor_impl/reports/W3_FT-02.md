All event identities below are `(session_id, sequence, kind)` from the Product `Session` persistence owner. The bridge `SessionEvent.event_id` list was empty for these fixtures because no streaming observation was emitted. `trajectory segment` means a generation/trajectory identity or boundary record; the current event schema has no such field, so absence is recorded rather than inferred as a boundary.

- Lock digest: unchanged `sha256:ff46ffa2d17c8551e5e61c214aac41fecc103310c25f0ef4b3d80bcc5cd335c2` → the same digest.
- Trajectory: no segment boundary or generation identity is represented.
- Publication: the session event file existed; the public read model remained `running`, event count `1`, with the unchanged Lock digest. No bridge event IDs were published.
- Admission/drain: the active-turn marker remained; no drain was started and no admission-close transition occurred.

This is the existing current-owner reject law, consistent with the focused active-turn control.
